# 🌿 Plantoria - Responsive Plant Selling Website
 
Plantoria is a modern and responsive plant-selling website built using **HTML** and **Tailwind CSS**. This project was created to practice real-world frontend development concepts, including responsive design, Flexbox, CSS Grid, and Tailwind utility classes.
 
## 🚀 Features
 
- Responsive design for mobile, tablet, and desktop devices
- Modern and clean user interface
- Multi-page website structure
- Product showcase using Grid layout
- Flexible layouts using Flexbox
- Well-organized navigation system
- Smooth spacing, alignment, and typography using Tailwind CSS
 
## 📄 Website Pages
 
### 🏠 Home Page
- Attractive landing section
- Introduction to Plantoria
- Featured products and promotional content
 
### 🌱 Products Page
- Displays a collection of plants and gardening products
- Grid-based card layout
- Responsive product showcase
 
### 📞 Contact Page
- Contact information section
- User-friendly layout for communication details
- Responsive and organized design
 
## 🛠️ Technologies Used
 
- HTML5
- Tailwind CSS
- Flexbox
- CSS Grid
- Responsive Web Design
 
## 📱 Responsive Design
 
Plantoria is fully responsive and adapts seamlessly to different screen sizes using Tailwind CSS breakpoints:
 
- Mobile Devices
- Tablets
- Laptops
- Desktop Monitors
 
The website maintains proper spacing, alignment, and visual hierarchy across all devices.
